# Spark Media Services branding

This Spark Systems fork produces the Android application ID
`com.sparksystems.sms` (`.debug` for debug builds).

The Gradle source namespace remains `org.jellyfin.mobile` intentionally. It is
an implementation namespace with extensive upstream references; changing it is
not required for the Android application identity and would make future
upstream synchronization unnecessarily risky.

This is a derivative of Jellyfin for Android. Keep `LICENSE.md`, all upstream
notices, and the complete corresponding source available with every release.
